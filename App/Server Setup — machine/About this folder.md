# Server Setup — machine

**This module is in two folders and this is the half the rented machine's own program may take.** The other is `App/Server Setup/`, which holds every act and every desktop reading. One plan governs both: `Preparation/Architecture/Server Setup.md`.

Here are the Blender lifecycle's judgements and the version a build answers, the add-on read-backs, the setup run and its record, recovery and re-running, who performs each step, and the ready action's steps with the libraries step's mapping. Nothing here opens a connection, reads a disk or runs a process. **The setup worker's own steps are not written**; this folder holds what exists.

**Why the module is in two folders.** The program a rented machine runs must never carry the SSH client or its C cryptography, and `App/Server Setup/` reaches both.
