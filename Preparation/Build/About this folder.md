# Build

This folder holds the **Build** documents — how the stage runs, and what gets made in what order. The actual app code does **not** live here; it lives in `App/`.

- **[Method](Method.md)** — how the stage runs: what a builder does when it meets something the plans left open, how the code is checked, and the moments that reach the Creator.
- **[The Plan](Plan.md)** — what gets made, in what order, and why that order.

The board is **`Audits/Build/Progress.md`**, which is where anyone picking this stage up starts.

What the Build stage is, and where it sits in the order, is set out in **`../Groundwork/Start Here.md`**.
