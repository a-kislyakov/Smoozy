# Sources — Keys

*Where the outside-world facts in the [Keys spec](../Keys.md) came from. The spec carries each fact's label in place; this file carries the citation behind it, and what that citation does not cover.*

- The key **comment** — its role in identifying a key, its `user@host` default, and its place as the last field of the public key that travels with the public half — is documented in the OpenSSH manuals `ssh-keygen(1)` and `sshd(8)` (man.openbsd.org), retrieved 2026-07-16. Label: **documented**. That Smoozy adopts the documented `user@host` default as its own pre-fill is Smoozy's choice, not part of the documented fact.
- The key **fingerprint** — a short code, effectively unique to a key, used to tell keys apart — is documented in the OpenSSH manual `ssh-keygen(1)` (man.openbsd.org), under the `-l` option, retrieved 2026-07-17. Label: **documented**.
- The **public half** being the half that goes onto the machine the user wants to log in to is documented in the OpenSSH manual `ssh-keygen(1)` (man.openbsd.org), in the FILES section, on the `id_*.pub` file: "The contents of this file should be added to ~/.ssh/authorized_keys on all machines where the user wishes to log in using public key authentication." Retrieved 2026-07-20. Label: **documented**. This source covers only that fact. Calling the owner of that machine "a provider" is Smoozy's own framing and is not part of it.
- The **private half** being the half needed to connect is documented in the OpenSSH manual `ssh(1)` (man.openbsd.org), in the AUTHENTICATION section: "The client proves that it has access to the private key and the server checks that the corresponding public key is authorized to accept the account." The same section states: "The server knows the public key, and only the user knows the private key." Retrieved 2026-07-20. Label: **documented**.
- The key **certificate** — an extra file that a trusted authority signs to vouch for a key — is documented in the OpenSSH manual `ssh-keygen(1)` (man.openbsd.org), in the CERTIFICATES section, retrieved 2026-07-17. Label: **documented**.
