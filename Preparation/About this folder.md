# Preparation

> **Blender researchers: stop here.** You may read your question sheet and the `Blender Sources/` folder — nothing else in this project. This folder is not for you: reading it turns your findings into echoes of this project's own guesses about Blender, which is the one failure the Blender Research stage cannot detect.

This folder holds all of the project's **planning documents** — and no code. It's organized by stage, and within each stage by module.

New here? Start with **`Groundwork/Start Here.md`** — the front door to the whole project.
