# Node setups

These questions are about node setups built inside a Blender file, and what files such a setup can make that file depend on. They are about node setups only — not about the ordinary ways a file records what it points at. Answer each one from your sources alone.

1. What files can a geometry node setup inside a `.blend` file cause that file to point at?
2. When a `.blend` file links a node setup from another `.blend` file, what does the linking file record about the files that setup uses, and how are they reached?
