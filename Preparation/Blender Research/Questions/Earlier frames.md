# Earlier frames

These questions are about a scene whose look on one frame depends on frames worked out before it, and what a render of chosen frames needs for that frame to look right. Answer each one from your sources alone.

1. What in a scene can make its look on one frame depend on the frames worked out before it? Name every kind your sources describe.
2. For each kind, from which frame does it begin, where is that set, and what is it when nobody has set it?
3. For each kind, can a script run with no window open find that first frame before anything is rendered? Say how certain your sources make it.
4. For each kind, what does a render of one frame show when no frame before it was worked out in that session, and when only the frames from the kind's own first frame onward were?
5. For each kind, what does a frame before its first frame show?
6. Can such a kind sit anywhere other than directly in the scene being rendered and still change what that scene shows? Name each such place, and say whether a script can find the kind and its first frame there.
7. Is there anything that makes one frame depend on earlier ones that a script cannot find, or whose first frame it cannot read? Name each.
8. Can a script ask, for a whole file, whether anything in it depends on earlier frames, or from which frame the earliest of them begins?
9. When such a kind has been baked, what does a render use, and can a script tell whether every frame the render needs is in the bake?
