# Sources — Method

*Where the outside-world facts in the [Method](../Method.md) came from. The document carries each fact's label in place; this file carries the citation behind it, and what it does not cover.*

*Note: how this project researches — blind framing, the handout, the labels, the standing lines, the topic split, permanent question numbers, how a disagreement with the Creator is handled, and what the comparison may and may not conclude — is Smoozy's own decision throughout, so none of it earns an entry here. Only the Blender facts the method is shaped around do.*

---

- **The Blender versions released from 4.5 onwards.** Blender's Release Notes page lists, newest first, **5.2 LTS** ("Released July 14th, 2026"), **5.1** ("Released on March 17th, 2026"), **5.0** ("Released on November 18th, 2025"), and then **4.5 LTS** ("Released on July 15th, 2025") heading the 4 series. Source: blender.org, Release Notes, retrieved 2026-07-30. Label: **documented**.

  What this does not cover, three things. It is the list of **released** versions only — the same page does not establish what unstable builds exist or how they are published, which is a research question in its own right (see the [Question register](../Question%20register.md), Builds 1 and 2). It fixes the list at a moment: new versions arrive, which is what the method's last section is written for. And which of these versions Smoozy chooses to **support** is the Creator's decision rather than a fact — the floor of 4.5 is Creator-stated and owned by the [module map](../../Specs/Whole%20app.md).

- **4.5 and 5.2 are marked LTS on that page; 5.0 and 5.1 are not.** Same source, same retrieval. Label: **documented**. What this does not cover: what the mark means for how long a version is maintained, which nothing here establishes, and whether it should bear on which versions Smoozy supports, which is the Creator's to decide.

- **blender.org refuses plain fetching.** Attempting to read the Release Notes page without a full browser returns a refusal; a real browser reads it normally. Label: **observed** (2026-07-30). It is a fact about the site rather than about Blender, recorded because the method depends on a researcher being able to read the sources at all. What it does not cover: whether the same holds for the manual and API documentation addresses, which was not tested, and whether it stays true — a site's behaviour can change without notice.
