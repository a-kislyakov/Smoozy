# Sources — Job files and outputs (Architecture)

*Where the outside-world facts in [Preparation/Architecture/Job files and outputs.md](../Job%20files%20and%20outputs.md) came from. The document carries each claim's label in place; this file carries the citation behind it, and what each source does **not** cover. Decisions Smoozy made get no entry.*

*Nothing was looked up for this file. Every citation below already exists somewhere under `Preparation/`, and where a claim has no source in the project it is recorded as an assumption or as unresolved rather than given one.*

*Three shapes appear below and no fourth. **Pointer** — the citation is owned by an input document of this stage, or by the spec that stage read, and the entry names that document and says what it does not cover. **Publication** — an outside publication's own words, with the address and the date read taken from the project. **No source** — an assumption or unresolved, with what breaks.*

*On the line-96 clause. The document's *"Do not read past the input documents"* is a reading discipline about not generalising a frozen machine observation, in the input documents' own words. It is not the Rule 2 waiver and does not stand in for one: this document quotes Blender Research comparison topics and joined answers, which are not this stage's input documents, and it carries one outside publication's published values. So it has a companion sources file, which is this.*

*On Blender. No Blender fact is re-derived here. Each entry names the joined answer, the comparison question, or the spec clause the document itself leans on, and nothing more. Where the document leans on a Blender fact and names no document for it, the entry says so.*

**15. Seventeen names written on a rental came back as fourteen files on a Mac, with every fetch reporting success.** N14, and unresolved item 10. Label: **observed**. **Pointer:** [One box with Blender on it](../One%20box%20with%20Blender%20on%20it%20—%20the%20reading,%20the%20listing,%20and%20the%20names%20that%20do%20not%20come%20back.md) §7.1 — names differing only in capitals collapsing to one file holding the **last** payload fetched, two spellings of one accented name doing the same, and a control in the same sitting proving the loss is at the receiving end. **Not covered:** one Mac, one case-insensitive volume at default settings; **Windows was not posed at all**, and the document says so.
