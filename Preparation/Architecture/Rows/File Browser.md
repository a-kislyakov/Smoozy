On Windows the earliness is worse than untested: Microsoft documents the last write time as not fully updated until every writing handle is closed, for any writer, and the narrower repair of reading the identity by opening the path has no first-party basis. With the earliness goes Row 201's third clause's saying and offering, which is a promise at risk rather than a wording**: where a real save moves no path-visible value the resume either starts over silently or carries on silently, and in neither case is the user told and offered. **The no-corruption promise itself survives on all three systems**, because the publication gate is contents arithmetic and lands nothing that changed — so `Method`'s second stop was weighed and not reached.
